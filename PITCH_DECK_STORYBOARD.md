## TECHNICAL IMPLEMENTATION DETAILS

### Animation Timing Standards
```
Entrance animations: 0.6s easeOut
Stagger delays: 0.2-0.3s between elements
Hover effects: 0.3s transition
Video transitions: 0.8s cross-fade
Text emphasis: 1s scale + color
```

### Framer Motion Code Pattern (All Slides)
```tsx
const containerVariants = {
  hidden: { opacity: 0 },
  visible: {
    opacity: 1,
    transition: {
      staggerChildren: 0.25,
      delayChildren: 0.3,
    },
  },
}

const itemVariants = {
  hidden: { opacity: 0, y: 20 },
  visible: {
    opacity: 1,
    y: 0,
    transition: { duration: 0.6, ease: 'easeOut' },
  },
}
```

### Color Emphasis Points
- **Green (#1DB954):** Success, value, solution
- **Cyan (#06B6D4):** Technology, intelligence, future
- **Amber (#F59E0B):** Opportunity, growth, premium
- **White:** Trust, clarity, premium feel

### Typography Hierarchy
- **Headline:** Strawford Black, 72-96px, white
- **Subheading:** Strawford Bold, 28-36px, colored accent
- **Body:** Inter Medium, 16-20px, gray-300
- **Label:** Inter Bold, 12-14px, uppercase

## SLIDE DECK DESIGN SPECIFICATIONS

### Overall Aesthetic
- Dark mode throughout (night-900 background)
- Glassmorphic cards with subtle blur effects
- Animated gradients in corners (orbital effects)
- Typography-first (minimal decorative elements)
- Consistent color language (green/cyan/amber)

### Animation Principles
1. **Purposeful:** Every animation serves the narrative
2. **Smooth:** No jarring cuts or abrupt transitions
3. **Fast:** Respect investor time (90 seconds total)
4. **Professional:** Premium feel without gimmicks

### Handoff to Engineering
```
Framework: React + Framer Motion
Package: TypeScript for type safety
Deployment: Vercel for investor access
Performance: <100ms animations, 60fps target
Accessibility: Full keyboard navigation, ARIA labels
```
